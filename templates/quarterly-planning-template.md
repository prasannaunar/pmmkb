# Quarterly PMM Planning Template

A working template for [Quarterly PMM Planning Framework](../frameworks/07-strategy-planning.md) (Category 7). Copy this file, fill in each section for the upcoming quarter, and review it against actuals at quarter close.

---

## 1. Business Goals This Quarter

List the 2-4 company or product goals PMM work must serve this quarter. If a goal doesn't map to at least one deliverable below, question whether it belongs here.

| Business goal | Owner | Target metric |
|---|---|---|
| e.g. Grow mid-market ARR | VP Sales | +$1.2M net new ARR |
| | | |

## 2. Framework-to-Goal Map

For each business goal, name the framework(s) most relevant to achieving it. Use [BY-SITUATION.md](../BY-SITUATION.md) or the [quick-reference cards](../quick-reference/) if you're not sure which framework fits.

| Business goal | Relevant framework(s) | Why |
|---|---|---|
| e.g. Grow mid-market ARR | STP Framework, ICP Development Methodology | Re-score mid-market segment fit before reallocating spend |
| | | |

## 3. Deliverables & Effort

| Deliverable | Framework applied | Owner | Estimated effort | Due |
|---|---|---|---|---|
| e.g. Refreshed mid-market ICP scorecard | ICP Development Methodology | | 1 week | Week 3 |
| | | | | |

## 4. Did We Apply It? Checklist

At quarter close, revisit every deliverable above and mark it honestly. A framework marked "planned" but never actually run should be dropped or rescoped next quarter, not carried over silently.

- [ ] Deliverable 1 applied as planned
- [ ] Deliverable 2 applied as planned
- [ ] Deliverable 3 applied as planned

---

**Success metric for this template:** every business goal above has at least one deliverable with a named framework, an owner, and a due date; and the "Did We Apply It?" checklist is filled honestly at quarter close, not left blank.
