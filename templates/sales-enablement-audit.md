# Sales Enablement Audit Checklist

A checklist against the [10-Step PMM Process](../frameworks/04-go-to-market-launch.md) and the [Sales Enablement Maturity Model](../frameworks/09-sales-enablement.md) (Category 9), to confirm nothing has fallen through the cracks before sales is expected to sell a product, segment, or positioning change.

Run this before any major launch, new-segment push, or repositioning reaches the sales team, and again quarterly as a standing health check.

---

## 1. Foundation

- [ ] Market sizing and segmentation documented ([STP Framework](../frameworks/01-market-customer-understanding.md))
- [ ] ICP scoring model current and live in the CRM ([ICP Development Methodology](../frameworks/01-market-customer-understanding.md))
- [ ] Win/loss analysis conducted in the last 90 days for the relevant segment ([Win/Loss Analysis Framework](../frameworks/06-product-experience-adoption.md))

## 2. Positioning & Messaging

- [ ] Positioning statement tested with target customers ([Dunford's 10-Step Positioning Process](../frameworks/02-positioning-messaging.md))
- [ ] Message architecture built and current ([Message Architecture](../frameworks/02-positioning-messaging.md))
- [ ] Draft messaging tested against a buyer panel before shipping ([Message Testing](../frameworks/02-positioning-messaging.md))

## 3. Competitive Readiness

- [ ] Battlecard exists and was updated in the last quarter for every competitor sales names most often ([Competitive Battlecard Framework](../frameworks/09-sales-enablement.md))
- [ ] Competitive Intelligence monthly scan is current ([Competitive Intelligence & Positioning Update Framework](../frameworks/07-strategy-planning.md), see also [competitive-intelligence-tracker.md](competitive-intelligence-tracker.md))

## 4. Sales Collateral & Deal Support

- [ ] Sales collateral created and mapped against the buyer's journey, with no stage-gap for the priority segment ([Buyer's Journey Content Map](../frameworks/09-sales-enablement.md))
- [ ] Deal-qualification content (Metrics, Decision Criteria, Competition) is current for reps running [MEDDIC/MEDDPICC](../frameworks/09-sales-enablement.md)
- [ ] Value-selling language for live conversations is documented ([Command of the Message](../frameworks/02-positioning-messaging.md))

## 5. Sales Training

- [ ] Reps have been trained on the current positioning and message architecture, not last quarter's version
- [ ] Reps can articulate the FAB (Feature-Advantage-Benefit) translation for the top 3 differentiators ([FAB Ladder](../frameworks/02-positioning-messaging.md))
- [ ] A named owner exists for keeping training current as positioning changes

## 6. Maturity Check

Score the enablement function itself, not just this launch, using the [Sales Enablement Maturity Model](../frameworks/09-sales-enablement.md):

| Dimension | Score (Ad Hoc / Organised / Optimised / Transformative) | Notes |
|---|---|---|
| Content governance | | |
| Training | | |
| Tooling | | |
| Cross-functional integration | | |

---

**Success metric for this checklist:** every box above is checked (not skipped) before sales is asked to run with a new positioning, segment, or launch; the maturity score is re-run quarterly and shows no dimension regressing without a documented reason.
